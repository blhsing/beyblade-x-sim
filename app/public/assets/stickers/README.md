# Beyblade sticker textures

These textures are cropped/resampled derivatives of the top-down Blade and
Lock Chip artwork associated with the [Takara Tomy Beyblade X product
catalog](https://beyblade.fandom.com/wiki/List_of_Beyblade_X_products_(Takara_Tomy)).
Each texture's exact Beyblade Wiki file page and original image URL are recorded
in `sources.json`.

Do not edit the generated WebP files or `app/src/render/sticker-manifest.json`
by hand. Regenerate both from the repository root with:

```text
python tools/fetch-stickers.py
```

The original characters, product designs, and artwork remain the property of
their respective owners. The source Wiki's licensing and file-page notices
apply to the source material.
