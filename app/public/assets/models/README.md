# Beyblade model references

These transparent WebP files are normalized derivatives of isolated part
renders published through the Beyblade Wiki and used to trace the high-poly
in-game silhouettes and exact visible surface layouts.

Do not edit the generated images, `sources.json`, or
`app/src/render/model-reference-manifest.json` by hand. Regenerate them from
the repository root with:

```text
python tools/fetch-model-reference.py
```

`sources.json` records the exact Wiki file page and original image URL for
every derivative. Original product designs and artwork remain the property of
their respective owners; the source Wiki's file-page notices apply.
